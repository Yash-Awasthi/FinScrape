Embedding a FinScrape widget

Serve this page from the origin you want to allow. The widget only frames when the parent query parameter names a bare origin: https://example.com, or http://localhost:3000 while developing. Everything else is a 400.

Track-record widget

The parent allowlist

The widget answers with Content-Security-Policy: ... frame-ancestors <parent>; ... and no X-Frame-Options. The browser then refuses to render the iframe on any other origin, and a wildcard is never emitted. To embed on a new site, add that site's origin to the request; the site itself needs no allowlist entry. 

<iframe src="https://api.example.com/embed/scenario?id=s1&parent=https://example.com"
        width="420" height="190" title="FinScrape scenario"></iframe>

Change localhost:3000 above to the origin this page is actually served from, or the browser will block the frame by design.
